PASOS PARA ACTIVAR EL FORO CON SUPABASE

1. Entra en https://supabase.com
2. Crea una cuenta o inicia sesión.
3. Crea un proyecto nuevo.
4. Entra en SQL Editor.
5. Copia el contenido del archivo supabase_sql.txt y ejecútalo.
6. Ve a Project Settings > API.
7. Copia:
   - Project URL
   - anon public key
8. Abre el archivo supabase-config.js.
9. Sustituye:
   PEGA_AQUI_TU_SUPABASE_URL
   PEGA_AQUI_TU_SUPABASE_ANON_KEY
10. Sube todos los archivos sueltos a GitHub.
11. Vercel actualizará la web.

IMPORTANTE:
- El login actual usa localStorage, es suficiente para una práctica sencilla.
- El foro sí es real: los mensajes se guardan online en Supabase.
- Todo el mundo que entre a la web podrá ver los mensajes publicados.
