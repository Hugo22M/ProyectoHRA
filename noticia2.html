Microsoft prepara nuevas funciones para Windows 11

Microsoft continúa trabajando en nuevas actualizaciones para Windows 11 centradas en productividad y rendimiento.

La compañía quiere incorporar nuevas herramientas basadas en inteligencia artificial para mejorar la experiencia del usuario.

Entre las novedades destacan mejoras en el explorador de archivos, optimización del sistema y nuevas opciones de personalización.

Microsoft también está desarrollando funciones inteligentes capaces de automatizar tareas dentro del sistema operativo.

Estas actualizaciones llegarán progresivamente durante los próximos meses a millones de usuarios de Windows 11 en todo el mundo.

Fuente: Microsoft / Xataka
